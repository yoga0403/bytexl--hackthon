# My Todo List

A clean, responsive, and lightweight Todo List web application built with vanilla HTML, CSS, and JavaScript.

## Features

- **Add Tasks**: Quickly create tasks with real-time input validation.
- **Mark Complete**: Check off tasks as you finish them with visual strike-through styling.
- **Task Counter**: Real-time counter displaying remaining active tasks.
- **Delete Tasks**: Remove individual tasks with a single click.
- **Clear Completed**: Batch delete all finished tasks.
- **Local Persistence**: Tasks are saved to `localStorage`, so your list persists across browser refreshes and sessions.
- **Responsive Design**: Clean UI that looks great on both mobile and desktop screens.

## Project Structure

├── script.js    # Application logic, state management, and local storage

## Getting Started

### Run Locally

No build tools or servers are required! Simply clone the repository and open `index.html` in any web browser:

1. Clone the repository:
   ```bash
   git clone https://github.com/yoga0403/bytexl--hackthon.git
   ```
2. Navigate into the directory:
   ```bash
   cd bytexl--hackthon
   ```
3. Open `index.html` in your browser:
   - On Windows: double-click `index.html` or run:
     ```powershell
     start index.html
     ```

## Technologies Used

- **HTML5**: Semantic document structure and accessible form controls.
- **CSS3**: Modern styling, Flexbox layout, and custom colors.
- **JavaScript (ES6+)**: DOM manipulation, event handling, and Web Storage API (`localStorage`).
